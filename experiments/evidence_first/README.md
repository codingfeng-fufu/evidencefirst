# EvidenceFirst Experiments

This folder is the active workspace for the new EvidenceFirst direction:
pre-generation graph-structural evidence-chain verification for KG-RAG.

The experiment goal is to test whether checking evidence-chain completeness
before generation, localizing graph gaps, and repairing missing graph structure
can improve trustworthy multi-hop QA.

## Current Experiment Loop

1. Run a small HotpotQA slice with `--variant evidence_first`.
2. Inspect chain diagnostics: completeness, missing entities, disconnected
   pairs, and fallback rate.
3. Tighten graph verification and repair logic.
4. Scale to 100 / 500 / 1000 questions only after the small slice has stable
   diagnostics.

## Current Status

The original local `comagraag/data/hotpotqa_sample.json` has incomplete HotpotQA
contexts: in the first 100 rows, 110/240 supporting-fact titles are absent from
the provided context. The reproducible context-complete input for current
EvidenceFirst evaluation is:

```text
experiments/evidence_first/data/hotpotqa_sample_hf_context.json
```

It is generated by restoring contexts by id from the HuggingFace HotpotQA
distractor validation split:

```bash
python experiments/evidence_first/repair_hotpot_contexts.py \
  --input comagraag/data/hotpotqa_sample.json \
  --output experiments/evidence_first/data/hotpotqa_sample_hf_context.json \
  --split validation
```

On the repaired-context first 100 rows, EvidenceFirst currently reaches
`EM 0.5800 / F1 0.6495`, meeting the short-term F1 >= 0.60 target. The primary
result files are:

- `experiments/evidence_first/results/hotpotqa_evidence_first_hfctx_n100_v1.csv`
- `experiments/evidence_first/results/hotpotqa_evidence_first_hfctx_n100_v1.jsonl`
- `experiments/evidence_first/results/hotpotqa_evidence_first_hfctx_n100_v1_usage.jsonl`

On the repaired-context 1000-row input, the frozen valid end-to-end split-KG
baseline is v4:

- `experiments/evidence_first/results/hotpotqa_evidence_first_hfctx_n1000_splitkg_v4.csv`
- `experiments/evidence_first/results/hotpotqa_evidence_first_hfctx_n1000_splitkg_v4.jsonl`

The first EM-improvement pass is v5 offline clean. It deterministically

## Offline Paper Analyses

The following commands recompute the saved statistical and diagnostic summaries
without new LLM calls:

```bash
python scripts/analyze_evidencefirst_stats.py \
  --out-dir results/analysis/evidencefirst_stats

python scripts/analyze_2wiki_evidence_support.py \
  --out-dir results/analysis/2wiki_support
```

The statistical summary writes `main_metric_ci.csv`,
`pairwise_mcnemar.csv`, `audit_overview.csv`, `audit_by_state.csv`, and
`audit_by_gap_type.csv`. These files should be used for paper claims about
confidence intervals, paired tests, repair-to-complete rates, and audit-state
splits.

## Baseline Boundary

Legacy CoMaGRAG variants remain available through `--variant default` and the
existing ablation modes. EvidenceFirst should be compared against them, but it
is now the main method under development.
